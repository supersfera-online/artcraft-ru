## 1. Frame в новых строках и уже стоящих

- **Правило:** в FigCraft имя инструмента/типа оставлять латиницей `Frame`. [из файла: translating.md, glossary.tsv, RULES-AUTHORSHIP.md]
- **В черновике новых UI-строк:** `Frame` (например «Слой в Frame с автолейаутом…», «импортированы как Frame»).
- **В уже стоящем каталоге** рядом встречаются и `Frame`, и «фрейм»/«фреймы» (в т.ч. в заметках импорта и в «выравнивается по своему фрейму»). Эти строки не трогал. [проверено]
- **Вопрос:** Для новых заметок импорта тоже держать `Frame` (как в черновике) или выровнять на уже стоящие «фреймы»? Старые не предлагаю править в этом заходе.

- **Решение:** в новых строках оставлять латиницей `Frame` (имя инструмента/типа и мн. ч. `Frames`). Уже стоящие вычитанные строки с «фрейм/фреймы» в этом заходе не выравнивать. «Show device frame» / «рамка устройства» — другой смысл (рамка устройства), не имя инструмента
- **Основание:** правило координатора: Frame латиницей только в FigCraft. Сверка каталога `apps/figcraft/crates/ui-egui/locales/ru.toml`: ключ `Frame` = «Frame», `Frames` = «Frames», большинство UI-строк уже с `Frame`. В отдельных уже стоящих фразах есть «фрейм» (например «выравнивается по своему фрейму») — факт каталога, вычитанные VanTan строки не трогать без отдельного поручения. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 2. Автолейаут

- В уже стоящем каталоге Auto layout → «автолейаут». В черновике так же («Убрать весь автолейаут»). [из файла]
- **Что в glossary.tsv:** отдельной принятой статьи на «Auto layout» в выборке этого захода не искал как конфликт; в программе термин уже устоялся.
- **Вопрос:** Подтвердить «автолейаут» как исключение FigCraft, если общий глоссарий пойдёт иначе.

- **Решение:** «автолейаут» — исключение FigCraft (как уже в каталоге)
- **Основание:** правило (а): в ru.toml Auto layout → «Автолейаут», «Убрать весь автолейаут» / «Убрать автолейаут». решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 3. Pretty / Balance (стиль переноса строк)

- **Английский:** Pretty, Pretty: full lines…; Balance, Balance: every line…
- **Вариант в черновике:** «Аккуратно» и «Баланс». [догадка от смысла типографского переноса, не копия чужого UI]
- **Вопрос:** Оставить так или есть принятые имена этих режимов в отделе?

- **Решение:** Pretty — «Аккуратно»; Balance — «Баланс»
- **Основание:** принятого имени в авторском глоссарии нет; вариант из черновика по смыслу типографского переноса, без копирования чужих UI. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 4. Pick select / Scope / Copy for AI

- **Pick select** → «Выбор указанием» (режим указания слоя, рядом с «Рамка выделения»). [догадка]
- **Scope** (область переменной) → «Область применения» («Scope: only {scope}»). [догадка]
- **Copy for AI / Copied comments for AI** → «Копировать для ИИ» / «Комментарии скопированы для ИИ». [догадка]
- **Вопрос:** Подтвердить или заменить (в частности AI / ИИ).

- **Решение:** Pick select — «Выбор указанием»; Scope (область переменной) — «Область применения»; Copy for AI / Copied comments for AI — «Копировать для ИИ» / «Комментарии скопированы для ИИ»
- **Основание:** авторского пункта нет; вариант из черновика, ИИ — обычная русская аббревиатура, не копия чужого UI. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 5. Уже стоящее, не менял

- Hug contents → «По размеру содержимого»; Fill container → «Заполнить контейнер»; Developer Mode → «Режим разработчика»; «Сохранить как пресет…» (Preset в glossary.tsv — «Набор»). [из файла]
- Если выравнивать «пресет» на «набор», это отдельное решение по уже стоящим строкам.
- **Решение:** Preset в FigCraft — «пресет» (исключение; не выравнивать на общее «Набор»). Сверка с каталогом: «Сохранить как пресет…», «Удалить пресет», «Пресеты», «Без пресета», «Пресеты коррекции» — везде «пресет», не «набор». «Набор» в каталоге занят другими ключами (Component set, Stylistic set, Kits). Hug contents / Fill container / Developer Mode — оставить как уже в каталоге
- **Основание:** поручение: Preset в FigCraft как у авторов. Проверено по ru.toml. Общее Preset → «Набор»; SolidCraft — «Пресет»; EffectCraft — «заготовка»; FigCraft — «пресет». решил координатор 20.11 (поручение правообладателя подтверждено им лично)
