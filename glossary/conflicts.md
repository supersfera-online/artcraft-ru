# Спорные термины: разночтения между программами и источниками

Составлено 20.11.2026 (America/Los_Angeles) терминологом отдела «Локализация ArtCraft». Только чтение; ничего наружу не отправлялось.

Как собрано **[проверено: подсчёт скриптом по файлам из sources.md]**: для каждого английского термина (1–3 слова, без плейсхолдеров, регистр и конечное «…» не учитываются) собраны все русские варианты из 14 каталогов. «Лексика» = варианты различаются не только окончанием и не только ё/е. Различие по роду/числу («Светлая»/«Светлый») сюда не попадает: оно обычно зависит от контекста **[догадка]**.

Важно: часть расхождений законна — один английский ключ значит глагол в меню и существительное в панели (Group: «Сгруппировать» / «Группа»), или разное в разных программах (Light: тема «Светлая» / источник «Свет»). Скрипт этого не различает; решает правообладатель **[догадка о законности — по каждому отдельно не проверено]**.

Решения в колонках «Решение» и «Основание» проставлены 20.11.2026 по правилам, которые координатор отдела передал как решения правообладателя (решил координатор 20.11 (поручение правообладателя подтверждено им лично)). Колонка заполнена терминологом; это не личная проверка указания правообладателя.

Общие правила (закреплены в README.md):
1. **ё** в интерфейсе — по словарю, без исключений (указал правообладатель лично 20.11.2026, 11:51 PT, чат SolidCraft; проверено). В Keywords (.desktop/metainfo и т.п.) дублируем форму без «ё» для поиска. «все» / «всё» — разные слова, не орфография; там как в программе по смыслу. Гнездо: щёлкнуть, щёлкните, щёлкать, щёлкайте, защёлка, щёлк — «ё»; щелчок, щелчка, щелчком, щелчки, щелчков — «е». Решил координатор 20.11 (Keywords); поручение правообладателя подтверждено им лично.
2. **Frame** латиницей только в FigCraft; в остальных программах переводим (смысл зависит от программы: кадр / рамка / Frame).
3. **Форма команд** в меню — как сейчас в каждой программе, не унифицировать (такие расхождения — не конфликт).
4. Вариант, принятый авторами конкретной программы, действует для этой программы: общее решение + исключения (см. decisions-20261120.md).

Правило выбора: (а) авторы программы/документа; (б) самый частый в каталогах, счёт N:M; (в) при равенстве — общепринятое в русских графических редакторах (без копирования чужих проприетарных файлов). Законные разные смыслы разводятся, не сливаются. Где правило не даёт однозначного ответа или решение спорно по смыслу — пометка «решил координатор 20.11 (поручение правообладателя подтверждено им лично)».

## Дополнение: ревизор (Rasterize, Amount) и новые списки MaterialCraft/GridCraft и EffectCraft

Решения внесены 20.11.2026 в glossary.tsv и decisions-20261120.md. Источники: terms-needed-apps.md, from-effectcraft.md. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

- **Amount:** смыслы разведены. Сила эффекта — «Величина» (а, PhotoCraft; это же общее для этого смысла). Число — «Количество» (б).
- **Rasterize:** общее — «Растеризовать» (б 2:1). Исключение PhotoCraft — «Растрировать» (а).
- **Normal:** разведены режим наложения / «обычный»; нормаль в 3D/PBR (MaterialCraft «Нормаль»); тип линии SolidCraft («Обычная», известная ошибка каталога).
- **Preset (EffectCraft):** исключение «заготовка» (уже стоящее меню программы). Общее по-прежнему «Набор»; SolidCraft — «Пресет».
- **Matte** (композиция) — «мат», не путать с Mask «маска»; в FilmCraft каталог даёт «Маска» (исключение, решил координатор 20.11 (поручение правообладателя подтверждено им лично)).
- **Audio:** общее «Аудио» (б, common/FilmCraft); исключение EffectCraft «Звук» (меню программы).
