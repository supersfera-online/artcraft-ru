## 3. Matte (в отличие от Mask)

- **Английский:** категория Matte; эффекты Depth Matte, ID Matte, Set Matte, Difference Matte, Matte Choker, Object Matte, Refine Hard/Soft Matte, Tracked Shape Matte; «цвет мата», «без мата».
- **Вариант в черновике:** «мат» (категория «Мат»), чтобы не слить с Mask → «маска» (маски в панелях и меню уже так: «Новая маска», «Интерполяция маски»). [догадка о различении двух смыслов]
- **Что в соседних каталогах:** FilmCraft ru.tsv — «Маска» и для Matte; craft-i18n `common.tsv` — «Мат», `photocraft.tsv` — «Маска». [проверено: поиск по каталогам]
- **Вопрос:** «Мат» / «матт» / «маска»? Нужно ли одно слово на Mask и Matte в EffectCraft, где оба понятия живут рядом?
- **Решение:** Matte (композиция / кеинг): «мат»; Matte (FilmCraft): «Маска» — решил координатор 20.11 (поручение правообладателя подтверждено им лично); Track Matte: «трек-маска»
- **Основание:** развести с Mask → «маска». В craft-i18n common.tsv — «Мат»; черновик и различение в EffectCraft — «мат». Не сливать, где оба понятия рядом. // исключение каталога: FilmCraft ru.tsv переводит Matte как «Маска». Общее для композиции — «мат». // (из файла: уже стоящее меню EffectCraft). ## 7. Буква «ё»

- В уже стоящем русском меню EffectCraft буквы «ё» нет ни разу. [проверено: 636 строк RUSSIAN в i18n.rs]
- README глоссария предлагает писать «ё» всегда, решение в conflicts.md. [из файла]
- В новых строках панелей «ё» стоит только в принятом термине глоссария Feather → «Растушёвка» (три строки: «Растушёвка конуса», «точек растушёвки», «Инструмент «Растушёвка маски»»). Остальной новый текст без «ё» («еще», «черный», «зеленый», «отчет» не встречался, «учет» в «с учетом»). [проверено]
- **Вопрос:** Выровнять панели на «ё» везде, оставить как сейчас (ё только в Растушёвка), или убрать «ё» и из этих трех строк ради единообразия с меню?
- **Решение:** буква «ё» (меню EffectCraft): «всегда «ё» (выровнять панели и, когда будут править, старое меню); не убирать «ё» из «Растушёвка»»
- **Основание:** правило координатора 20.11: всегда «ё». В старом меню EffectCraft «ё» нет — это отставание, не исключение.
