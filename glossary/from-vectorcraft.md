## 1. Clipping mask

- **Английский:** clipping masks (новое: `{label}: the clipping masks hide the selected art`).
- **Вариант в черновике:** «маски обрезки». [из файла: уже стоящие `@msg` VectorCraft, например «его маски обрезки вложены слишком глубоко»]
- **Что в glossary.tsv:** clipping mask → «обтравочная маска» (предложен). [проверено]
- **Вопрос:** Для VectorCraft оставить «маска обрезки» (как уже в каталоге) или выровнять на «обтравочная маска»?

- **Решение:** для VectorCraft — «маска обрезки» (как уже в каталоге); общее / PhotoCraft — «обтравочная маска»
- **Основание:** правило (а): в живом каталоге VectorCraft уже «Маска обрезки» / «маски обрезки». В PhotoCraft locales/ru/photocraft.tsv — «Обтравочная маска» (не вытеснять). Смыслы не сливать. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 2. Script / сценарий / скрипт

- **Контекст:** в уже стоящем каталоге рядом живут «Проверить сценарий», «движок скриптов», «файл скрипта». [проверено]
- **Вариант в черновике:** для движка и файла скрипта — «скрипт» (как в уже стоящих `@msg`); для списка установленных — «сценарии» (как «Проверить сценарий»). Новые: «Удалить движок скриптов», «Список движков скриптов», «Список установленных сценариев», «Диалоги файлов скрипта недоступны».
- **Вопрос:** Свести к одному слову во всей программе или оставить это разделение (пользовательский сценарий / технический скрипт)?

- **Решение:** оставить разделение, как уже в каталоге VectorCraft: пользовательский сценарий — «сценарий»; движок и файл — «скрипт»
- **Основание:** правило (а) + смыслы разводить. Уже стоят «Проверить сценарий» и «движок скриптов» / «файл скрипта». Не сводить к одному слову во всей программе. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 3. Pattern (регулярное выражение, не узор)

- **Английский:** `\ at end of pattern` (`@msg`).
- **Вариант в черновике:** «шаблон» (`\ в конце шаблона`), не «узор». [догадка: это сообщение разбора шаблона, не заливки узором]
- **Что в glossary.tsv:** Pattern → «Узор» (для заливки/декора). [проверено]
- **Вопрос:** Подтвердить «шаблон» для regex/pattern matching.

- **Решение:** «шаблон» для regex / pattern matching; Pattern как заливка/декор по-прежнему «Узор»; SolidCraft — «Массив»
- **Основание:** законный другой смысл, не сливать с Pattern → «Узор». Черновик «\ в конце шаблона» подтверждается. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 4. Emboss / Face / Single Graphic / Map Graphic

- **Emboss** → «Тиснение» (имя эффекта; в каталоге рядом «Свечение», «Неон и свечение»). [догадка от смысла]
- **Face** (3D, рядом с Materials и наложением графики) → «Грань». Уже стоящее: «Рисовать скрытые грани». [из файла]
- **Add as Single Graphic** → «Добавить как один графический объект». [догадка; Art в этой программе уже «рисунок»]
- **Map Graphic** → «Наложить графику» (уже стоящее меню «Наложение графики» / Map Art). [из файла]
- **Вопрос:** Подтвердить эти четыре варианта.

- **Решение:** Emboss (эффект, VectorCraft) — «Тиснение»; Face (3D) — «Грань»; Add as Single Graphic — «Добавить как один графический объект»; Map Graphic — «Наложить графику»
- **Основание:** (а) уже стоящие строки: «Рисовать скрытые грани», меню «Наложение графики» / Map Art; в каталоге Emboss → «Тиснение», Face → «Грань». Не путать с Bevel & Emboss → «Скос и рельеф». решил координатор 20.11 (поручение правообладателя подтверждено им лично)

- **Вопрос:** не требуется, если «фрагмент» остаётся общим решением.

- **Решение:** «фрагмент» — как уже в каталоге VectorCraft, общее решение для этого смысла
- **Основание:** правило (а): в уже стоящем каталоге Slice везде «фрагмент». решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## 6. Имена, намеренно оставленные по-английски

По тестам авторов `MENU_KEEP_AS_IS` / `kept_menu_names_are_menu_labels_left_in_english` и заголовку уже стоящего `ru.tsv` не добавлялись строки для: VectorCraft, OpenType, имён рабочих сред (Essentials, Essentials Classic, Automation, Layout, Painting, Printing and Proofing, Tracing, Touch, Typography, Web) и пресетов сетки перспективы (`[1P-High View]` и др.). Русский каталог входит в `KEEPS_MENU_NAMES`: любая строка перевода этих ключей ломает тест. [проверено: tests.rs]

Языковые имена вроде «Bulgarian», «German: Swiss» переведены по образцу уже стоящих («Французский», «Английский: Великобритания»), это языки расстановки/орфографии, не пункты выбора языка интерфейса. [из файла]
- **Решение:** не переводить: VectorCraft, OpenType, имена рабочих сред (Essentials и др.) и пресеты сетки перспективы (`[1P-High View]` и т.п.) — как требуют тесты авторов `MENU_KEEP_AS_IS`. Языковые имена («Bulgarian» и т.п.) переводить по уже стоящему образцу («Французский», «Английский: Великобритания»)
- **Основание:** проверено по заголовку ru.tsv и тестам авторов: перевод этих ключей ломает каталог. решил координатор 20.11 (поручение правообладателя подтверждено им лично)

## Итоговое правило «щёлк-/щелч-» (20.11.2026, позже)
