# Список правок — SolidCraft

Адресат: **SolidCraft**.

Составлено терминологом отдела «Локализация ArtCraft» 20.11.2026 (America/Los_Angeles). Пометки отдела на момент сверки; рассылку делает координатор.

Рабочие файлы исполнителя: `solidcraft/` (в т.ч. `solidcraft/solidcraft/assets/locales/ru.json`, `crates/ui-text/locales/ru.json`, `terms-solidcraft-ru.tsv`).

Норма: `glossary/glossary.tsv` и `glossary/decisions-20261120.md`. Пометка: «решил координатор 20.11 (поручение правообладателя подтверждено им лично)».

Колонки: файл (путь от ``), ключ, сейчас, надо, основание. Форму команд и род/число с тем же корнем («как в программе») не включали. «все» / «всё» не сводили правилом «ё».

Число правок в этом файле: **6**.

В список включены расхождения с итоговым глоссарием по поправкам 1–5 и по уже принятым исключениям SolidCraft (Pattern «Массив», Preset «Пресет», OK «ОК»).
Не включались: разные смыслы одного английского слова (Normal как «нормаль» vs тип линии «обычная», Send, Output и т.п.), форма команд, заголовки ленты вроде ALIGN/CHECK, «все»/«всё».
В `assets/locales/ru.json` @ рабочая копия на box: `ui.circle` / `ui.drawing_detail.circle` уже «Окружность»; `Pattern`/`Preset` уже «Массив»/«Пресет»; `Mesh` уже «Меш». Их не дублировали.
«Полный круг» в значении полного оборота (full circle / 360°) не трогать — это не термин Circle.
Клоны в `packaging/src/solidcraft` и `cli/src/solidcraft` в этот файл не включались: адресат — исполнитель SolidCraft, рабочие файлы `dept/l10n/solidcraft/`.
