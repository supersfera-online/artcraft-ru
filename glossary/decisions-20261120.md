# Решения по глоссарию — 20.11.2026

Собрано терминологом отдела «Локализация ArtCraft» для показа правообладателю. Правила, по которым заполнялись решения, координатор отдела передал как решения правообладателя от 20.11.2026. Для этой работы это **со слов координатора 20.11.2026, лично не проверено**. Ничего наружу не публиковалось.

Краткие правила: всегда «ё»; Frame латиницей только в FigCraft; форму команд не унифицировать; авторский термин программы действует в этой программе (общее + исключения); (а) авторы, (б) частота N:M, (в) при равенстве общепринятое без копирования чужих UI; смыслы разводить; спорное — «на взгляд правообладателя».
