# Решения по глоссарию — 20.11.2026

Собрано терминологом отдела «Локализация ArtCraft» для показа правообладателю.

Правила, по которым сначала заполнялись решения, координатор отдела передал как решения правообладателя от 20.11.2026. Позднее координатор решил спорные пункты по поручению правообладателя; правообладатель лично подтвердил это поручение в чате. Для этой работы это **решение координатора 20.11.2026 (поручение правообладателя подтверждено им лично)**. Пометка: «решил координатор 20.11 (поручение правообладателя подтверждено им лично)». Ничего наружу не публиковалось.

Краткие правила: в интерфейсе «ё» — по словарю, без исключений (указал правообладатель лично 20.11 11:51 PT); в Keywords (.desktop / metainfo и т.п.) дублировать форму без «ё» для поиска; Frame латиницей только в FigCraft; форму команд не унифицировать; авторский термин программы действует в этой программе (общее + исключения); (а) авторы, (б) частота N:M, (в) при равенстве общепринятое без копирования чужих UI; смыслы разводить.

Поправки координатора 20.11 к утверждению спорных:

1. Workspace в SolidCraft = «Рабочая область»; ключ `prefs.workspace` выровнять.
2. В Keywords дублировать форму без «ё» для поиска; в интерфейсе только «ё».
3. Timeline: общее «Шкала времени»; в FilmCraft — то, что уже в его каталоге (правило а).
4. Circle в CADCraft и SolidCraft = «Окружность»; в графических программах — «Круг».
5. Mesh = «сетка» там, где авторы уже так пишут, иначе «меш» (б).

## Решил правообладатель лично

20.11.2026, 11:51 PT (America/Los_Angeles). правообладатель велел писать по словарю (чат SolidCraft; **проверено**). Ранее в тот же день по этому гнезду звучало иное указание; итоговое правило — словарное.

«Ё» пишем там, где его требует словарь; **исключений из этого правила нет**. В гнезде: щёлкнуть, щёлкните, щёлкать, щёлкайте, защёлка, щёлк — через «ё» (ударный слог); щелчок, щелчка, щелчком, щелчки, щелчков — через «е» (безударный). Повелительное — «щёлкните»; существительное — «щелчок», «двойной щелчок», «щелчок правой кнопкой».
