# Термины на проверку терминологу

Составлено при переводе недостающих строк craft-i18n (`locales/ru/`), ветка `ru-catalog-20261120`.  
Отдельский `glossary/glossary.tsv` и `GLOSSARY.md` репозитория просмотрены; ниже — спорные или отсутствующие там термины. Уже стоящие в каталогах переводы не менялись.

Формат: английский ключ; мой вариант в этой работе; контекст и почему это на проверку.

| en | Мой вариант | Контекст |
|---|---|---|
| Frame | Кадр | Ключ без уточняющего context в `common.tsv` (общий каталог). В отдельском глоссарии «Frame» принят **только для FigCraft** и оставлен латиницей (conflicts.md, «Главные 15» №11); для остальных программ не решено. В уже существовавшем `locales/ru/photocraft.tsv` стояло «Кадр» (идентичный английский ключ). В common поставлен тот же вариант, идентичный override из photocraft убран (CI запрещает бесполезный override). Альтернативы: «Рамка», «Frame». **[догадка смысла: кадр изображения/анимации; не проверено по коду приложений]** |
| To | До | Ключ без context в `common.tsv`. Парный `From` в `locales/ru/common.tsv` уже переведён как «С». В `locales/ru/photocraft.tsv` для того же ключа `To` уже стояло «До» (оставлено и перенесено в common, override убран). Пара «С» / «До» может быть неидеальной (часто «с … по …» или «от … до …»). Альтернативы: «По», «К». **[догадка: конец диапазона; не проверено по коду]** |

| Reset Essentials | Сбросить «Основное» | PhotoCraft, имя рабочей среды Essentials. В каталоге не нашёл закреплённого названия этой среды. Альтернативы: «Сбросить Essentials», «Сбросить основные рабочие среды». |
| Lining / Proportional Lining / Tabular Lining | Заголовочные / Пропорциональные заголовочные / Табличные заголовочные | Типографика (наборные цифры lining vs oldstyle). «Oldstyle» в том же каталоге уже «Старостильные цифры». «Заголовочные» — мой вариант для lining figures; альтернативы: «маюскульные», «lining». |
| Paint Overlay | Наложение краски | Контекст `cameraRaw`. Смысл: режим/оверлей при правке RAW. Не уверен в термине. |
| Working CMY Plate | Рабочая пластина CMY | Цветоделение. Альтернативы: «Рабочая форма CMY», «Рабочая фотоформа CMY». |
| Rate (liquify) | Скорость | Контекст `liquify`. Может быть «степень» или «интенсивность», не «скорость». |
| Developing {name} | Проявка {name} | Контекст `cameraRaw`; в соседних новых строках использовано «RAW-проявка». |
| High Memory Photoshop Document | Документ Photoshop с высоким расходом памяти | Похоже на формат/предупреждение о большом документе, не имя продукта. |
| Data Sets as Files | «Наборы данных как файлы» | Имя команды/функции, в кавычках. |
| Concavity | Вогнутость | Параметр наконечника стрелки. |
| Before (Y) | До (Y) | Контекст `cameraRaw`, клавиша Y. Парность «до/после»; не путать с ключом `To`. |

`AutoSave` → «Автосохранение» и `@plural {n} byte|{n} bytes` → `{n} байт\|{n} байта\|{n} байт` в глоссарии отдела не было; взяты из уже существовавших ru-строк того же репозитория (`wordcraft.tsv` и `pdfcraft.tsv`) и обычной русской компьютерной нормы. На отдельное решение не выношу, если терминолог не возражает.

| Hotbar / hotbar | панель быстрого доступа | PdfCraft: «Add Tools to Hotbar», «Drag hotbar», «Hotbar settings», «Remove from hotbar». В глоссарии отдела нет. Альтернативы: «горячая панель», «Hotbar». |
| Bitmap images | Черно-белые изображения | PdfCraft, группа в проверке разрешения (рядом Colour images / Gray images). Имеются в виду, скорее, 1-битные изображения, не любая растровая картинка. Альтернатива: «Штриховые изображения». |
| Look | Вид | PdfCraft, короткая подпись. Может пересекаться с «View». Альтернативы: «Оформление», «Внешний вид». |
| Float (drag anywhere) | Свободно (перетаскивать куда угодно) | PdfCraft, положение панели. Альтернатива: «Плавающая». |
| Freehand-Highlight | Выделение от руки | PdfCraft, имя инструмента через дефис. |
| Grads | Грады | Угловая единица (400 градов в окружности), не «градиенты». |
| ICP-Brasil Seal | Печать ICP-Brasil | Имя схемы/печати; латиница ICP-Brasil сохранена. |

| Open (context `spacing`) | Разреженный | WordCraft, пресет интервала абзаца, не команда «Файл → Открыть». В ROADMAP craft-i18n этот омоним описан отдельно. Альтернативы: «Свободный», «Открытый». Глоссарий «Открыть» сюда не подходит. |
| Emphasis Mark | Знак акцента | WordCraft, восточноазиатская типографика (акцентные точки над/под текстом). Альтернативы: «Маркер акцента», «Знак выделения». |
| Limit and | Ограничение и | WordCraft, обрезанная подпись без продолжения в ключе; смысл без соседнего UI неясен. |
| Word sources | Источники Word | WordCraft, источники библиографии? Или импорт из Word. Не уверен. |
| Language data | Языковые данные | WordCraft; в GLOSSARY.md репозитория термин Language data закреплён по-английски как понятие (словари, переносы). В интерфейсе перевёл. |
