# Чеклисты скриншотов русского интерфейса

19 программ: 18 из `packaging/src` (anicraft, cadcraft, craft-anything, craft-launcher, deckcraft,
designcraft, effectcraft, figcraft, filmcraft, gridcraft, lightcraft, materialcraft, pdfcraft,
photocraft, soundcraft, texturecraft, vectorcraft, wordcraft) и SolidCraft. Один файл на программу:
`<программа>.md`.

## Кто и как

- **Снимки делает правообладатель на своём компьютере.** Бот туда не заходит и ничего там не запускает.
- Идти по файлу сверху вниз: включить русский (раздел 1), снять кадры из раздела 2, отметить [x].
- Имена файлов: `<программа>-NN-<что>.png`, например `photocraft-02-menu-file.png`. Номер не менять,
  даже если пункт пропущен — тогда в чеклисте написать «нет» и почему.
- Готовые снимки положить в одну папку и передать ревизору отдела локализации; он сверит их с чеклистом
  и отчётами `review/reports/` и запишет итог в конец чеклиста.

## Что важно знать перед съёмкой

- Снимок показывает **установленную версию**, а не локальные черновики на box. Русские каталоги,
  которые исполнители сейчас дописывают (craft-i18n на ветке `ru-catalog-20261120`, правки в `apps/`,
  русские поля `.desktop` в `packaging/src/*` — коммит «отдел локализации packaging…»),
  в программу на компьютере не попали, пока её не пересобрали. **[проверено: git log / git status клонов 20.11.2026]**
  Поэтому первый проход — снимок исходного состояния; повтор — после сборки с новыми каталогами.
- У deckcraft, materialcraft, soundcraft, texturecraft в выпущенном коде русского нет; у anicraft
  ru в списке, но каталога нет. Для них снимки только подтверждают «русского нет».
  **[проверено: код и docs клонов]**
- EffectCraft: русский есть только для меню (таблица `RUSSIAN`), панели останутся английскими. **[проверено: код]**

## Пометки в чеклистах

- **проверено (источник)** — прочитано в файле клона на box, источник указан (файл:строка);
- **догадка** — по смыслу, без проверки (например, как вызвать ошибку, как называется панель);
- **не проверено** — неизвестно, отметить по факту на снимке.

## Как обновить

Чеклисты собирает `review/tools/gen_checklists.py` (ручные сведения — таблица `PROGRAMS` в начале
скрипта, остальное — из клонов, глоссария и последних отчётов `review/reports/`):

```
python3 review/tools/gen_checklists.py
```

Скрипт перезаписывает только `<программа>.md` в этой папке. Если в чеклисте уже отмечены
снимки — сначала сохранить копию.
