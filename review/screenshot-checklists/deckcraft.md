- Путь: переключателя языка нет — интерфейс только на английском — **проверено: docs/localization-parity.md:5**

- Где лежит перевод: пока нет (craft-i18n `locales/ru/deckcraft.tsv` — черновик, программа его не читает)
- **Русского в программе пока нет** — снимки ниже фиксируют исходное (английское) состояние.
- Нужен ли перезапуск после смены языка: **не проверено** — отметить по факту: [ ] сменился сразу  [ ] нужен перезапуск
- Версия программы на компьютере: ____________ (из «О программе»)

## 3. На что смотреть на каждом снимке

- [ ] нет английских слов там, где рядом русские (кроме списка «не переводится» ниже)
- [ ] текст не обрезан, не вылезает за кнопку/колонку, нет «…» посреди слова
- [ ] буква «ё» рисуется (нет квадратиков и пустых мест)
- [ ] числа с подписями склоняются: 1 файл / 2 файла / 5 файлов / 21 файл
- [ ] горячие клавиши и подчёркнутые буквы меню не пропали
- [ ] многоточие «…» у пунктов, которые открывают окно, стоит так же, как в английском
